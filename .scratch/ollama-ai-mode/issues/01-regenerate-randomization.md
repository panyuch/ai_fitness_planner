# 01: 算法模式重生成随机化

**What to build:** 用户点「重生成」/「清空锁餐重生成」时，未锁餐次的食材在同类池内换一批、分量有小幅浮动（±10% 后收敛），全天宏量依然达标；锁定的餐次保持不动。首次生成与固定输入下结果保持可复现（与 v1.0 逐字节一致），既有行为与单测不回归。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 生成器接受可注入 seed；缺省/固定 seed 输出与 v1.0 一致
- [x] 重生成（未锁餐）后至少一餐食材或分量与上次不同
- [x] 锁餐后重生成：锁定餐内容不变、未锁餐变化
- [x] 分量浮动后宏量仍达标（热量偏差 ≤2.6%、蛋白偏差 ≤1%）
- [x] 前端「重生成」「清空锁餐重生成」自动携带新 seed；首次生成不携带
- [x] 既有单测在默认 seed 下全绿
