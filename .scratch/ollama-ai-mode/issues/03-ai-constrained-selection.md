# 03: AI 受控选材闭环

**What to build:** AI 模式下，LLM 只从本地食材库候选清单里挑选每餐食材（受控选材），服务端校验全部食材合法后由算法引擎按宏量目标分配分量——生成结果全部是库内常见食材、宏量依然准确达标。已锁定餐次会告知 LLM 以便避让，生成后仍以本地锁定内容覆盖；LLM 输出含库外食材或结构异常时整体回退本地，绝不产出坏结果。

**Blocked by:** 02 (Ollama provider 接入)

**Status:** ready-for-agent

- [ ] 提示词并入食材库候选清单（id + 名称）与已锁定餐次摘要
- [ ] AI 输出 Schema 改为仅食材 id 清单（不含克数/宏量）
- [ ] 服务端校验全部 id 在食材库内；任一非法 / 结构异常 → 整体回退本地
- [ ] 合法结果：食材全部来自库内，分量由算法分配且宏量达标
- [ ] 锁定餐以本地内容覆盖 AI 输出对应餐次
- [ ] 提示词内容与 id 校验为可单测纯函数，测试就位
