# 04: 表单字段提示/示例

**What to build:** 输入表单的每个字段提供提示或示例（如"体重填 60–80kg""步数填 5000–12000"），降低新手填写门槛，让不知如何填的用户有参照。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 基本信息字段（年龄/体重/身高/体脂）有合理区间提示
- [ ] 训练与活动字段（频率/强度/工作性质/步数/有氧）有示例或说明
- [ ] 提示不遮挡输入、样式与表单一致
- [ ] 仅改 `app/page.js` / `app/globals.css`
